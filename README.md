# OffWorkCountdown
# 【下班倒计时】Rainmeter 桌面小组件 v1.0.0

距离下班还有多久？距周五还有几天？发薪还有多久？今天又赚了多少？
一个干净好看的桌面倒计时，一眼看完。

---

### ✨ 功能
* **实时下班倒计时**（时:分:秒）
* **距周五天数**
* **距发薪日天数**
* **今日已赚金额**（按日薪 × 已工作时长）
* **右侧可自定义插画**

---

### 💻 系统要求
* **Windows 7 及以上**
* **已安装 Rainmeter 4.5+**
  官网：[https://www.rainmeter.net/](https://www.rainmeter.net/)

---

### 📥 安装方法
1. 安装并打开 Rainmeter
2. 双击 `OffWorkCountdown_1.0.0.rmskin`
3. 按提示完成安装（建议勾选安装后自动加载）
4. 组件出现在桌面后，可直接拖动位置

---

### ⚙️ 自定义设置
右键组件 → 编辑设置，或修改文件：
`Documents\Rainmeter\Skins\OffWorkCountdown\@Resources\Variables.inc`

**可改项：**
* **上班/下班时间**（默认 9:00–18:00）
* **发薪日**（默认每月 10 号）
* **日薪**（默认 300 元）
* **WorkOnWeekend**：1=周末也倒计时，0=周末显示休息

**换右侧图片：**
用 PNG 覆盖：`Documents\Rainmeter\Skins\OffWorkCountdown\@Resources\Images\mascot.png`  
然后右键组件 → **刷新**

---

### 📌 说明
* 「周五」= 距离下一个周五还有几天（今天是周五则为 0）
* 「今天赚了」= 日薪 × 已工作时长 ÷ 当天总工时
* 若按月薪估算：日薪 ≈ 月薪 ÷ 21.75
